部署观察看板是我给静态站点准备的小工具。它解决的问题很朴素：项目上线后，不只要看构建成功，还要确认关键页面真的能打开、RSS 能访问、草稿没有泄漏。

## 检查内容

第一版只做四件事：

- 请求首页、列表页和详情页，确认状态码正常。
- 检查页面里是否存在关键标题和导航。
- 检查 RSS 是否包含公开文章，并排除草稿。
- 保存一次桌面截图，方便肉眼快速判断布局有没有明显坏掉。

## 为什么不用重型监控

这个工具不是为了替代专业监控服务。它更像个人项目的上线后清单，把“我应该手动点一遍”的事情自动化掉。

## 下一步

我想把它做成 GitHub Actions 模板：每次部署完成后跑一遍，失败时直接把页面、截图和错误摘要贴到 issue 里。
