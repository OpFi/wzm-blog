# Green Blog Adaptation Design

## Goal

Create an original green-themed Chinese personal blog inspired by the structure of `flowersink.com`, without copying its brand, text, images, exact layout, or styling.

## Reference Takeaways

The reference site presents a personal technical blog with a warm background, rounded article cards, selected article previews, RSS/SEO metadata, and friend links. The adaptation should reuse this general content pattern while changing the visual identity to a green palette and the content to Wang Ziming's blog.

## Scope

- Shift the color system from slate/blue to green and warm paper tones.
- Rework the homepage around a blog index: intro header, featured articles, latest writing, friend links, and a compact sidebar.
- Add a green-themed friend-link data set with believable placeholder blogs.
- Preserve existing content collections, detail routes, daily page, projects page, RSS, sitemap, draft filtering, reading time, and adjacent post navigation.
- Avoid pixel-perfect cloning of the reference site.

## Verification

The build verification script should assert green theme markers, homepage featured articles, friend links, latest article cards, existing content routes, daily page, reading metadata, RSS behavior, and draft exclusion.
